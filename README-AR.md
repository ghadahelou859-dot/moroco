# كرت عبد القادر وسلمى — GitHub Pages

جميع الملفات مرتبة في مستوى واحد لتسهيل الرفع.

1. افتحي مستودع GitHub جديدًا.
2. اختاري **Add file → Upload files**.
3. ارفعي كل الملفات الموجودة هنا معًا، وليس ملف ZIP.
4. افتحي **Settings → Pages**.
5. اختاري **Deploy from a branch** ثم **main** و **/(root)**.
6. اضغطي **Save** وانتظري ظهور رابط الموقع.

لا تغيّري أسماء الصور أو الفيديو أو الموسيقى، لأنها مرتبطة بالكود بالأسماء نفسها.
